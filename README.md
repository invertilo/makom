## 📌 Español

### ¿Qué pasó con Makom?
Makom nació como un atlas comunitario enfocado en mapear lugares kosher, kehilot y tefilot. Con el objetivo de brindar una mejor infraestructura, confiabilidad y experiencia a los usuarios, el proyecto original ha sido retirado.

Actualmente, el proyecto oficial y vigente es **[Kosher Mercav](https://kosher.mercav.lat)**.

Este repositorio se mantiene únicamente como referencia y punto de redirección hacia el nuevo sitio.

---

## 📌 English

### What happened to Makom?
Makom started as a community atlas project to map kosher places, synagogues, and communities. In order to provide a superior user experience, scalable infrastructure, and expanded capabilities, Makom has been superseded.

The current active and official project is **[Kosher Mercav](https://kosher.mercav.lat)**.

This repository is maintained as an archive and redirect point to the new platform.
